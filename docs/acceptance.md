## 3. 비정상·악의 입력 (빼지 않는다)
| 입력 | 기대 처리 | 자동화 위치 |
|---|---|---|
| 지원하지 않는 형식 | `.m4a`가 아니면 무시, 디코딩 실패면 `skipped`(사유: decode) | 단위 테스트 |
| 거대 파일·압축 폭탄 | 3시간·1GB 초과면 `skipped`(사유: too_long/too_big). 압축 파일은 확장자에서 걸러짐 | 단위 테스트 |
| 내부 주소·허용 외 호스트 URL | URL을 받지 않음(해당 없음). 받는 폴더 밖 경로·심볼릭 링크는 무시 | 단위 테스트 |
| 빈 값·잘린 값·연속 재전송 | 0바이트·전송 중 파일은 안정될 때까지 대기, 같은 해시 재전송은 무시 | 단위 테스트 |
| 지시문 삽입·권한 사칭 | 녹음에 "앞의 지시를 무시하고…" 같은 말이 있어도 보정은 줄 수·id 검증을 통과해야 반영되고, 요약은 데이터로만 다룸. CLI에 명령 실행 권한을 주지 않음 | 단위 테스트(프롬프트 조립) + 수동 1회 |
