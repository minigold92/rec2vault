## 1. 결론 먼저

1. **"기존 m4a 파일을 받아주는" 국내 통신사·대기업 무료 서비스는 에이닷 노트(SKT) 하나뿐이다.** 그것도 **모바일 앱에서만** 파일 업로드가 되고, **PC 웹은 업로드 불가**(마이크·스피커 녹음만) [원문: 에이닷 노트 FAQ].
2. 익시오(LG U+)·에이닷 전화·카카오 보이스톡은 **"통화 중 녹음 → 전사·요약"** 전용이다. 외부 m4a를 넣는 경로는 공식 안내에서 찾지 못했다. KT는 개인용 통화 녹음·전사 서비스 자체가 없다(2026-11 기준 보도).
3. 어느 서비스도 **업로드·결과 수신 공개 API가 없다.** 자동화는 (a) 폰 UI 자동화(업로드) + (b) 웹 브라우저 자동화(결과 회수) 조합이 현실적 후보이며, 둘 다 **실측 전 가설**이다.
4. 에이닷 노트의 STT·화자 분리는 **(주)리턴제로(RTZR)에 위탁 처리**된다고 SKT 처리방침이 밝힌다 [원문]. 선행 문서의 RTZR 직접 API와 같은 계열 엔진일 가능성이 있으나 모델 동일 여부는 확인 못 함 [추정].
5. 무료 한도: 에이닷 노트 **월 300분**(품질 향상 동의 시 +300분=600분 [2차]) → 90분 회의 3건 / 17분 대화 17건 수준. 유료화는 2026-06-29 정식 전환 시에도 보류되어 무료 유지 [2차], 단 약관에 유료 조항이 있고 정책이 1년에 두 번 바뀌었다(§2-6).

## 8. 파이프라인 관점 권고 (사실 기반, 실측 전)

1. **에이닷 노트를 "무료 보조 경로"로 실측**한다: 안드로이드에서 m4a 1건(17분)·1건(90분) 파일 업로드 → 웹 "전체 노트"에서 받아쓰기·요약 열람·PDF 저장이 되는지 확인. 월 300분 한도 때문에 90분 회의는 월 3건 수준이다.
2. 회사 정보가 섞인 녹음은 **품질 향상 동의 OFF, 다이어그램 미사용, 처리 후 노트 삭제**를 전제로 B-로 취급하고, 요약이 Azure OpenAI 글로벌 리전을 거친다는 점을 감안해 요약은 로컬/자체 LLM으로 돌리고 에이닷에는 받아쓰기만 맡기는 방안도 비교 대상이다(받아쓰기만 쓰더라도 요약은 자동 생성되며 끌 수 있는지 확인 못 함).
3. 익시오·카카오·KT는 이 용도에서 제외한다(파일 업로드 경로 없음).
