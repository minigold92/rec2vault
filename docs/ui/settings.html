‘처리 데이터 삭제’가 지우는 것What ‘Delete processing data’ removes

  • 원본 사본과 중간 결과The recording copy and working files
  • 대화 관련 기록, 할 일·필드 소유 기록Transcript-related records and note ownership data
  • 같은 파일이 다시 와도 처리하지 않도록 지문(해시)만 남겨요A fingerprint (hash) so the same file isn't processed again

지우지 못하는 것What it can't remove

  • 폰의 원본 녹음과 받는 폴더의 파일The original on the phone and the file in the inbox
  • 볼트의 회의록 노트 (직접 지워 주세요)The note in your vault (delete it yourself)
  • 외부 요약 엔진(Codex 등) 쪽에 남은 기록 — 각 서비스 정책을 따라요Anything kept by external engines (Codex etc.) — their policies apply
