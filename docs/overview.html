녹음기는 이미 주머니에

갤럭시 기본 녹음 앱은 녹음 품질과 파일 관리가 충분합니다. 새 기기를 살 이유가 없습니다.

바꾼 것은 “AI가 어디서 도는가”

받아쓰기·화자 분리를 서버 대신 집의 Mac mini에서 돌립니다. 월 분량 한도와 녹음 파일 외부 업로드가 없어집니다.

결과는 내 노트에

앱 안에 갇히지 않고 노트 앱의 파일로 쌓여, 검색·링크·목록 정리를 다른 기록과 함께 할 수 있습니다.
