## 안건별 논의

### 홈 화면 개편

- 쟁점: 최근 3개월 앱 문의 중 대출 연장 관련 문의가 38%였으며, 현재 대출 연장 버튼이 메뉴 안쪽에 있어 찾기 어렵다는 의견이 제기됨 [t003] [t004]
- 의견: S2(오지안 추정)는 홈 화면 맨 위 칸에 내 대출 현황을 표시하고 해당 화면에서 바로 연장할 것을 제안함 [t006]
- 결론: 홈 화면 첫 칸을 내 대출 현황으로 변경하고 대출 연장 버튼을 포함하기로 함 [t014]

### 대출 연장 API 응답 시간

- 쟁점: S3은 API 응답이 느릴 경우 사용자가 대출 연장 버튼을 여러 번 누를 수 있다고 설명함 [t007]
- 의견: S1은 응답 시간을 먼저 측정하자고 요청함 [t008]
- 결론: S3이 대출 연장 응답 시간을 측정해 공유하기로 함 [t009]

### 디자인 및 개편 범위

- 의견: S1은 어르신 이용자가 많으므로 글자 크기를 함께 검토해 달라고 요청함 [t012]
- 의견: S2(오지안 추정)는 글자를 크게 한 버전과 현재 글씨 버전을 모두 시안에 포함하겠다고 함 [t013]
- 결론: 푸시 알림으로 반납일을 알려주는 기능과 신규 가입자 온보딩 화면은 다음 개편으로 미루기로 함 [t014]
